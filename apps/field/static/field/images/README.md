# Images for the Mitra pages

Drop your own pictures here, using these exact file names. Missing files are fine: the pages
fall back to a green gradient.

| File | Where it shows | Suggested size |
| --- | --- | --- |
| `hero.jpg` | Big banner on the login page and dashboard | 1600 x 700, landscape, keep the left side calm so text is readable |
| `logo.png` | Top bar, next to the name (transparent background, white or light) | about 200 x 60 |
| `farmer.jpg` | Banner on the Register a farmer page | 1200 x 400 |
| `field.jpg` | Banner on the Add a plot page | 1200 x 400 |

Keep each file under 500 KB so the pages load quickly on a mobile connection.
